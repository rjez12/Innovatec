# Innovatec
Proyecto: Parque Tecnológico Innovatec (Árboles y Grafos)

Este proyecto es una aplicación de Windows Forms desarrollada en C# 

El programa implementa dos estructuras de datos principales:

Un Árbol General para administrar la jerarquía organizativa del parque.

Un Grafo No Dirigido para modelar y calcular las rutas más cortas entre los edificios del parque (usando el algoritmo de Dijkstra).

Cómo Ejecutar el Proyecto

Clonar este repositorio.

Abrir el archivo de solución (.sln) con Visual Studio 2022

Informe Técnico y Explicación

La explicación detallada de las decisiones técnicas, la implementación de las estructuras de datos (Árbol y Grafo) y la prueba de la ruta más corta se encuentran en el informe técnico oficial del proyecto.
